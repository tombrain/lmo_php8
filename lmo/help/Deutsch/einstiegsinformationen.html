1. Einleitung

Herzlich Willkommen zum neuen Liga Manager Online. Mit diesem Skript können Sie Ihren Besuchern einen Ergebnisdienst über Ihre Lieblingsligen anbieten. Die gesamte Verwaltung der Ligen läuft dabei direkt auf dem Server ab; Sie tragen nur noch die Ergebnisse ein und Ihre Besucher erhalten sofort die aktuellen Tabellen, Statistiken usw. - Keine Fremdsoftware, keine zeitraubenden Exporte und Uploads mehr!

Es ist ratsam, wenn Sie sich ein Bookmark/Favoriten in Ihrem Browser für den Adminbereich (.../lmoadmin.php) einrichten, damit Sie immer schnell darauf zugreifen können. Im User-Bereich ist aus Sicherheitsgründen kein Link auf den Adminbereich vorhanden (damit niemand auf dumme Gedanken kommt).

Die Besucher können das Skript über die Datei lmo.php starten. Wie man den LMO an seine eigene Homepage anpasst, steht im Abschnitt Anpassung des LMO. Zu jedem Link erhalten Ihre Besucher einen Tooltip, so daß Sie keine weiteren Erklärungen zur Benutzung des Skripts geben müssen.

Der Adminbereich ist über lmoadmin.php erreichbar. Beim ersten Aufruf legen Sie dort Ihren Benutzernamen und Ihr Passwort fest (siehe Installation). Rufen Sie lmoadmin.php deshalb direkt nach dem Hochladen auf, damit Ihnen niemand zuvorkommt.

2. Systemvoraussetzungen

  • Unix- oder Windows-Webserver (empfohlen: Apache)
  • PHP 8.0 bis PHP 8.4
  • empfohlen: PHP-Erweiterung GD (für Grafiken wie die Fieberkurve)
  • empfohlen: JavaScript- und CSS-fähiger Browser

3. Installation

  1. Entpacken Sie das ZIP-Archiv und laden Sie den Ordner lmo auf Ihren Webspace hoch. Achten Sie darauf, dass die Verzeichnisstruktur erhalten bleibt. Einen Installer gibt es nicht mehr.
  2. Rufen Sie lmo.php im Browser auf. Der LMO richtet sich dabei selbst ein: Er ermittelt Dateipfad und Webadresse, legt die Konfiguration im Verzeichnis config an (aus den Vorlagen in config-default) und erzeugt die benötigten Verzeichnisse.
  3. Rufen Sie sofort danach lmoadmin.php auf. Beim ersten Aufruf legen Sie dort Benutzernamen und Passwort des Hauptadministrators fest (mindestens 8 Zeichen). Ein voreingestelltes Konto gibt es nicht; wer lmoadmin.php als Erster aufruft, legt das Passwort fest.
  4. Erscheint die Meldung „Der Ordner config/ ist nicht beschreibbar“, setzen Sie mit Ihrem FTP-Programm die Zugriffsrechte (chmod) und rufen den LMO erneut auf:
    775 oder 777 - die Verzeichnisse config, ligen, output, addon/spieler/stats und addon/tipp/tipps jeweils mit allen Unterverzeichnissen
    664 oder 666 - die Ligen im Verzeichnis ligen
    Welche Werte nötig sind, hängt vom Server ab; bei den meisten Anbietern ist das heute nicht mehr erforderlich.
  5. Nur falls Dateipfad oder Webadresse falsch erkannt werden (z. B. hinter einer besonderen Weiterleitung), können Sie beide fest vorgeben. Legen Sie dazu mit einem Texteditor die Datei config/init-parameters.php an:
    <?php
      $lmo_dateipfad='/absoluter/pfad/zum/lmo'; //Dateipfad zum LMO
      $lmo_url='https://www.adresse.ihres/lmo'; //absolute URL zum LMO
    ?>
  6. Update des LMO: Laden Sie die neuen Dateien über die vorhandenen. Ihre Konfiguration, Ligen und Konten bleiben erhalten. Neue Einstellungen einer neueren Version ergänzt der LMO beim nächsten Aufruf automatisch in Ihren vorhandenen cfg.txt-Dateien, ohne Ihre Werte zu verändern. Einen Ordner install aus einer älteren Version können Sie löschen.

4. Login/Logout

Wenn Sie den Adminbereich betreten, sehen Sie zuerst eine Eingabemaske, mit der Sie sich beim System anmelden müssen. Beim allerersten Aufruf erscheint stattdessen die Ersteinrichtung, in der Sie Benutzernamen und Passwort des Hauptadministrators festlegen; danach sind Sie direkt angemeldet. Weitere Benutzer und Passwortänderungen verwalten Sie unter Optionen.

Wenn Sie eingeloggt sind, haben Sie rechts oben im Menü immer auch einen Befehl Logout, mit dem Sie sich aus dem Adminbereich ausloggen können. Das sollten Sie der Sicherheit wegen auch immer am Ende einer Sitzung tun.
